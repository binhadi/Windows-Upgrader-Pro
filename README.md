## 📖 نبذة عن الأداة / Overview

**Windows Upgrader Pro** هي أداة ذكية وموجهة لمساعدة المستخدمين على ترقية وتحديث أنظمة Windows بسلاسة، فحص توافق مكونات الجهاز مع إصدارات ويندوز الحديثة، وتجاوز قيود التثبيت المزعجة أو إصلاح أخطاء خدمات التحديث المتعطلة (Windows Update Troubleshooter).

**Windows Upgrader Pro** is an intuitive Windows deployment and upgrade companion engineered to simplify OS upgrades, verify hardware readiness, repair corrupted Windows Update components, and ensure an effortless transition to the latest Windows builds.

---

## ✨ المميزات الرئيسية / Key Features

- 🔄 **فحص التوافق والمتطلبات (Hardware Compatibility Check)**: فحص المعالج، ذاكرة الرام، رقاقة TPM، ومساحة التخزين لضمان توافق الترقية.
- 🛠️ **إصلاح أخطاء Windows Update**: إعادة تشغيل الخدمات الحيوية وتنظيف ذاكرة التخزين المؤقت لحل مشكلات التوقف والأكواد الشائعة (0x800...).
- ⚡ **تسهيل عملية الترقية (Streamlined Upgrade)**: خطوات تفاعلية ومباشرة ترشد المستخدم خلال عملية الترقية دون فقدان الملفات أو البرامج الشخصية.
- 🛡️ **حفظ الأمان والاستقرار**: أداة موثوقة تحافظ على بيانات المستخدم وإعدادات النظام الحالية.

---

## 💻 متطلبات النظام / System Requirements

- **نظام التشغيل / OS**: Windows 10 أو Windows 11.
- **الاتصال**: اتصال نشط بالإنترنت لتنزيل حزم الترقية وملفات التثبيت.
- **الصلاحيات**: **يجب تشغيل الأداة بصلاحيات مسؤول النظام (`Run as Administrator`)**.

---

## 🚀 طريقة الاستخدام / How to Use

1. قم بتنزيل ملف `WindowsUpgraderPro.exe` من قسم [Releases](../../releases) أو من هذا المستودع.
2. انقر بزر الفأرة الأيمن على الملف ثم اختر **تشغيل كمسؤول (Run as Administrator)**.
3. انتظر حتى تقوم الأداة بفحص النظام وعرض حالة التوافق والترقيات المتاحة.
4. اتبع التوجيهات التي تظهر على الشاشة لإتمام الترقية أو إصلاح خدمات التحديث.
