## 📖 نبذة عن الأداة / Overview

**Windows Upgrader Pro (الإصدار الاحترافي V6.0)** هي أداة متطورة تم تصميمها وهندستها بواسطة **علي هادي (Ali Hadi)** لمساعدة المستخدمين على ترقية وتحديث أنظمة Windows 10 و Windows 11 بأبسط الخطوات وأعلى درجات الأمان، مع ميزة تخطي قيود التثبيت الصارمة (مثل متطلبات رقاقة TPM 2.0 والمعالجات غير المدعومة) مع ضمان كامل للاحتفاظ بالملفات الشخصية والبرامج المثبتة دون فقدان أي بيانات.

تتميز الأداة بواجهة رسومية عصرية تدعم اللغتين العربية والإنجليزية، وإمكانية التبديل بين النمط الليلي (Dark Mode) والنهاري (Light Mode)، بالإضافة إلى فحص التوافق الصامت التلقائي.

**Windows Upgrader Pro V6.0** is an intuitive Windows deployment companion developed by **Ali Hadi**. It automates in-place upgrades to Windows 11, bypasses artificial hardware restrictions (TPM 2.0 & Unsupported CPUs), and preserves all personal files and installed applications with zero data loss.

## ✨ خطوات ومراحل الترقية الأربعة / Upgrade Workflow

1. 📂 **1. اختيار الآيزو (Select ISO)**: تحديد مسار ملف نسخة ويندوز بصيغة `.iso` المتواجد على جهازك.
2. 🔗 **2. ربط الملف (Mount ISO)**: تثبيت وربط ملف الآيزو تلقائياً كنظام أقراص وهمي لقراءة ملفات التثبيت.
3. 🔍 **3. فحص التوافق (Compatibility Check)**: فحص توافق لغة النظام وإصدار الويندوز للتأكد من مطابقتها وتفادي أي أخطاء.
4. 🚀 **4. الترقية (In-Place Upgrade)**: بدء الترقية الآمنة مع تفعيل خيار الحفاظ على الملفات والإعدادات والتطبيقات.

## ⚡ خيارات التثبيت وتخطي المتطلبات / Bypass & Advanced Options

- 🛡️ **تخطي متطلبات TPM 2.0 و CPU**: حقن مفاتيح التخطي الرسمية في سجل النظام (Registry Bypass Keys) لتجاوز قيود التثبيت على الأجهزة القديمة أو غير المدعومة رسمياً.
- 🏢 **وضع الخادم (Server Setup Bypass)**: إمكانية تخطي فحص التوافق الإجباري كلياً باستخدام معالج التثبيت الخاص بنسخ الخوادم.
- 🔄 **التحديثات الديناميكية (Dynamic Updates)**: خيار تفعيل أو تعطيل تنزيل أحدث التحديثات أثناء الترقية لتسريع العملية أو ضمان أحدث الحزم.
- 📊 **لوحة معلومات النظام اللحظية**:
  - كشف تلقائي لنوع النسخة (مثل `Windows 11 Pro`).
  - لغة النظام (مثل `en-US` أو `ar-SA`).
  - رقم البناء الحالي (`Build Number`).
  - المساحة التخزينية الحرة المتاحة على القرص.
- 📋 **سجل عمليات حي (Live Console Log)**: نافذة أوامر تفاعلية تسجل كل خطوة وإجراء بنجاح.

## 💻 متطلبات النظام / System Requirements

- **نظام التشغيل / OS**: Windows 10 أو Windows 11.
- **المساحة التخزينية**: توفير مساحة حرة كافية على قرص النظام (يوصى بـ 25GB فأكثر).
- **الصلاحيات**: **يجب تشغيل الأداة بصلاحية مسؤول النظام (`Run as Administrator`)**.

> [!IMPORTANT]
> **تنبيه هام جداً**:  
> يجب أن تتطابق لغة ونوع ملف الآيزو (ISO) مع لغة ونوع نظامك الحالي لضمان خيار الاحتفاظ بكافة الملفات والتطبيقات الشخصية مفعلًا.

## 🚀 طريقة الاستخدام / How to Use

1. قم بتحميل الملف التنفيذي `WindowsUpgraderPro.exe` من قسم [Releases](../../releases) أو من هذا المستودع.
2. انقر بزر الفأرة الأيمن على الملف ثم اختر **تشغيل كمسؤول (Run as Administrator)**.
3. اضغط على **استعراض** لاختيار ملف الآيزو ثم اضغط **ربط الملف**.
4. تأكد من تفعيل خيارات التخطي المطلوبة (Bypass TPM & CPU).
5. اضغط على **بدء الترقية والاحتفاظ بالملفات** وانتظر اكتمال العملية.
